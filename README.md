# Сайт «Древо жизни», управляемый из Mini CRM

- `schema.json` — описание блоков для редактора в CRM и текущее содержимое страницы.
- `build.py` — собирает `index.html` из содержимого.
- `sync.py` — раз в минуту забирает опубликованное из CRM и пересобирает страницу.
- `setup.sh` — установка на сервер.
- `make_schema.py` — генератор `schema.json` (если нужно изменить набор блоков или полей).

Установка: `sudo ./setup.sh`. Токен сайта вводится при установке и хранится в `/etc/drevo-sync.env`.
